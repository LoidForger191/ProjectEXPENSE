# ProjectEXPENSE
# 💰 Expense Tracker

A simple, lightweight expense tracking web app built with **vanilla HTML, CSS, and JavaScript**. No frameworks, no build tools, no dependencies — just the web.

## ✨ Features

- Add, view, and delete expenses
- Track income and expenses separately
- Real-time balance and total calculations
- Data persistence using `localStorage` (survives page refresh)
- Responsive design — works on mobile and desktop
- Zero dependencies, zero build step

## 🛠 Tech Stack

| Technology | Purpose |
|------------|---------|
| HTML5 | Structure |
| CSS3 | Styling & Layout |
| JavaScript (ES6+) | Logic & Interactivity |
| localStorage | Client-side data persistence |
